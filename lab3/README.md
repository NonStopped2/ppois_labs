# Лабораторная работа №3 — «Интернет-магазин»

Предметная область: «Интернет-магазин».

Реализованы базовые значения, каталог, покупатели, адресная книга,
избранное, лояльность, цены, акции, купоны, склад, резервы, корзина, расчёт предложений,
доставка, документы заказа/оплаты, комплектация, частичные возвраты и координация покупок
(53 предметных класса), подтверждённые отзывы, сравнение товаров и отчёты.
Подключены сборка и постоянные C++ unit-тесты.
Работает предметный цикл оформления → оплаты → комплектации → отправки → получения,
отмена, истечение, повтор покупки и частичные возвраты с осмотром.
Реализованы полные версионированные JSON-снимки и безопасная файловая замена.
Работает CLI с операторским/покупательским режимами и воспроизводимым `--demo`.
Нативная упаковка с проверкой переноса и распаковки работает.
**Публикация в Releases ожидает согласования тега и политики выпуска.**
Контракт снимков: [docs/SNAPSHOTS.md](docs/SNAPSHOTS.md).
Предметная область отличается от лабораторной №2 — «Почта».

## Сборка и тесты

Из корня репозитория:

```bash
cmake -S . -B build/lab3 -DBUILD_LAB1=OFF -DBUILD_LAB2=OFF -DCMAKE_BUILD_TYPE=Debug
cmake --build build/lab3 --parallel 4
ctest --test-dir build/lab3 -L '^lab3-' --output-on-failure
./build/lab3/lab3/shop_cli --demo
./build/lab3/lab3/shop_cli --script lab3/examples/purchase.input
```

Язык C++20, CMake ≥3.20, Catch2 v3.8.1 и nlohmann/json v3.12.0
(загрузка с проверкой SHA-256). При первой сборке нужен доступ к сети.
Справка/сценарии: [docs/CLI.md](docs/CLI.md).
`LAB3_ENABLE_COVERAGE=ON` включает LLVM-инструментацию;
`LAB3_ENABLE_SANITIZERS=ON` — AddressSanitizer/UndefinedBehaviorSanitizer.
Обычная корневая сборка по умолчанию включает все реализованные работы.

## Модель и ограничения

Один магазин и склад, физические товары, валюта BYN, один поток, учебные часы.
Оплата моделируется без настоящих банковских данных. Реализованы явные команды
сохранения и загрузки полного состояния в версионированный JSON без базы данных.

Первые классы: `Money` — целые копейки и безопасные вычисления;
`Address` — неизменяемый снимок адреса; `ContactDetails` — контакты;
`TimeWindow` — полуинтервал времени. `ManualClock` — технический источник времени,
не дополнительный предметный класс для количественного требования.
Подробная спецификация и этапы: [docs/DOMAIN.md](docs/DOMAIN.md).
Фактические поля и методы: [docs/CLASS_CATALOG.md](docs/CLASS_CATALOG.md).

`python3 lab3/tools/coverage.py --build-dir build/lab3` после сборки с покрытием.
