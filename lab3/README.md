# Лабораторная работа №3 — «Интернет-магазин»

Предметная область: «Интернет-магазин».

**В разработке.** Реализованы базовые значения, каталог, покупатели, адресная книга,
избранное, лояльность, цены, акции, купоны и распределение скидок (21 предметный класс).
Подключены сборка и постоянные C++ unit-тесты.
Полный магазин, CLI и JSON-сохранение пока не реализованы.
Предметная область отличается от лабораторной №2 — «Почта».

## Сборка и тесты

Из корня репозитория:

```bash
cmake -S . -B build/lab3 -DBUILD_LAB1=OFF -DBUILD_LAB2=OFF -DCMAKE_BUILD_TYPE=Debug
cmake --build build/lab3 --parallel 4
ctest --test-dir build/lab3 -L '^lab3-unit$' --output-on-failure
```

Язык C++20, CMake ≥3.20, Catch2 v3.8.1 (загрузка с проверкой SHA-256).
`LAB3_ENABLE_COVERAGE=ON` включает LLVM-инструментацию;
`LAB3_ENABLE_SANITIZERS=ON` — AddressSanitizer/UndefinedBehaviorSanitizer.
Обычная корневая сборка по умолчанию включает все реализованные работы.

## Модель и ограничения

Один магазин и склад, физические товары, валюта BYN, один поток, учебные часы.
Оплата моделируется без настоящих банковских данных. Планируются явные команды
сохранения и загрузки полного состояния в версионированный JSON без базы данных.

Первые классы: `Money` — целые копейки и безопасные вычисления;
`Address` — неизменяемый снимок адреса; `ContactDetails` — контакты;
`TimeWindow` — полуинтервал времени. `ManualClock` — технический источник времени,
не дополнительный предметный класс для количественного требования.
Подробная спецификация и этапы: [docs/DOMAIN.md](docs/DOMAIN.md).
Фактические поля и методы: [docs/CLASS_CATALOG.md](docs/CLASS_CATALOG.md).

Проверки текущего этапа: `python3 lab3/tools/quality.py` и
`python3 lab3/tools/coverage.py --build-dir build/lab3` после сборки с покрытием.
Сбор профилей ограничен C++ unit-тестами lab3; тесты предыдущих работ и CLI
не увеличивают показатель. Знаменатель включает `src/` и исполняемые строки `include/`.
