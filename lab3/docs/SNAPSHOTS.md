# Полные JSON-снимки магазина

`SnapshotCodec` и `SnapshotStore` — технический модуль `shop_persistence`,
не дополнительные предметные классы для количественного требования.
JSON-зависимость отсутствует у `shop_core`. Используется nlohmann/json **3.12.0**
с закреплённым SHA-256 архива в CMake.

## Содержимое

Формат: `ppois-online-store`, версия **1**. Сохраняются учебное время и счётчик ID,
политики и сроки, каталог, покупатели/контакты/адреса/избранное/корзины/лояльность,
цены/акции/купоны, склад/приходы/резервы, заказы с типизированной историей, попытки,
оплаты и возвраты денег, исполнения, возвратные заявки/осмотры, отзывы/голоса
и точные параметры/результаты идемпотентных команд.

Производные индексы восстанавливаются. Ревизии и денежные кеши проверяются.
Снимки строк покупки не обращаются к актуальным ценам или характеристикам
при восстановлении. Состояние заменяется целиком, а не объединяется с текущим.

## Загрузка

1. Ограниченный файл → строгий JSON-разбор.
2. Новые объекты с проверкой их конструкторов и переходов; история заказа
   воспроизводится, а не назначается произвольным статусом.
3. Сверка владельцев, ID, ссылок, состояний/количеств резервов и исполнений,
   квот купонов, финансовых документов, возвратных диапазонов, лояльности,
   отзывов и журнала команд.
4. Сравнение канонического представления: неизвестные поля, изменённые кеши
   и незаметная нормализация идентификаторов не принимаются.
5. Только затем небросающий swap временного состояния с текущим магазином.

Отклоняются повторные ключи JSON, повторные ID, неизвестные версии/перечисления,
неверные типы, дробные числа, переполнение int64, повреждённые связи/итоги.
Лимиты: файл до 16 MiB, глубина JSON до 128, отдельные коллекции до 100000 записей.
Импорт произвольно отредактированных неканонических JSON-документов не обещается.
Это не криптографическая подпись и не доказательство подлинности истории.

Ошибка загрузки сохраняет текущий магазин, включая учебное время и журналы.
Восстановленные команды оплаты/возврата можно повторить без нового эффекта.

## Запись

Весь JSON формируется до изменения файлов. Затем рядом с назначением создаётся
уникальный временный файл через `O_CREAT | O_EXCL` с правами 0600, выполняются
проверенные write/close и rename. При обычной ошибке временный файл удаляется,
старый снимок не заменяется неполным. Каталоги автоматически не создаются.

Первая версия файлового слоя рассчитана на Linux/macOS. Нет автосохранения,
системных банковских данных, базы данных или обещания стойкости к отключению
питания: fsync не реализован. Снимок содержит контакты и адреса покупателей;
его не следует публиковать с реальными персональными данными.

## Проверки

Предметное покрытие и покрытие JSON/файлов измеряются **раздельно**, оба со строгим >90%:

```bash
python3 lab3/tools/coverage.py --build-dir build/lab3 --scope core
python3 lab3/tools/coverage.py --build-dir build/lab3 --scope persistence
ctest --test-dir build/lab3 -L '^lab3-persistence$' --output-on-failure
```

Тесты JSON не увеличивают показатель `core`. Сторонняя библиотека, тестовые
исходники и файлы других лабораторных не входят в производственный знаменатель.
